# Interface Studio

Open the palette icon in the top bar. V4 persists workstation UI preferences in `localStorage` under `lens-ui-prefs-v4`.

The customization layer deliberately keeps `OK`, `NOK`, and `Warning` colors fixed. Accent color changes only navigation, focus, buttons and decorative emphasis, so changing the theme cannot alter inspection-result meaning.

Available settings:

- Theme: Midnight, Graphite, Arctic
- Accent: Azure, Cyan, Violet, Emerald
- Density: Compact, Comfortable, Spacious
- UI scale: 86–116%
- Card radius: 6–24 px
- Surface opacity: 76–100%
- Motion and ambient glow toggles
- Sidebar collapsed / expanded
- WT History, Inspection Viewer and Lens Details dashboard proportions
- Viewer-focus, History-focus and Balanced presets
- Show/hide dashboard command bar, KPI cards, WT thumbnail strip and lower workspace
